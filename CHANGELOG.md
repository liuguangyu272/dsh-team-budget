# Changelog

## 0.1.0 — 2026-11-12

First public release. Native DSH administrator panel and self-hosted DeepSeek gateway; managed member keys; monthly/daily/shared budgets; model access controls; streaming usage receipts; historical spending charts; key rotation/deletion; first-run gateway connection. Includes deployment templates, Chinese/English documentation and 29 local tests.

Compatibility checked against DSH 0.2.1-rc.5 and Node.js 24.9+.
