## 中文短文案

做了一个 DeepSeek Harness 团队预算插件：管理员生成成员密钥、设置每月预算和模型权限，在 DSH 中看用量和费用趋势。成员只填 key 和网关地址，不需要装插件，也不限校园网。网关可自托管；官方密钥不分发给成员。

目前是 0.1.0，MIT 开源，附中英文说明和测试。欢迎需要给实验室 / 小团队管理 DeepSeek 用量的朋友试用并提反馈。费用为估算，以官方账单为准。

https://github.com/liuguangyu272/dsh-team-budget

## English announcement

I built DSH Team Budget: a native DeepSeek Harness administrator plugin plus a self-hosted gateway for per-member API keys, spending visibility, monthly budgets and model permissions. Members only configure a managed key and base URL; no member plugin or shared network is required.

The first public release includes Chinese/English docs, deployment examples and 29 local tests. It is MIT licensed and currently tested against DSH 0.2.1-rc.5. Cost tracking is an estimate from provider usage receipts, not invoice data. Feedback from small teams and labs is welcome.

https://github.com/liuguangyu272/dsh-team-budget
